# Stage 7B revised — open enrollment

The invitation-only admission design is superseded by the 21 October 2026 product decision and Stage 7C. Normal enrollment has no UID allowlist or participant cap. Any registered eligible consenting user may join an approved active experiment when its server enrollment switch is enabled. Adult eligibility, immutable assignments, withdrawal and deletion protections remain.

See [Stage 7C readiness](mina-stage-7c.md) for architecture, scaling, evidence gates, local results and deployment/device preparation. No deployment, publication, production configuration changes or distribution was performed.
